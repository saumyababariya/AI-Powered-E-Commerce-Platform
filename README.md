# AI-Powered Smart Shopping Intelligence E-Commerce Platform

A full-stack e-commerce platform built using React.js, Spring Boot and MySQL featuring intelligent shopping analytics, Shopping DNA Score, AI Personality Insights, Budget Manager, Admin Dashboard, Recommendation Engine and more.

## Tech Stack

- React.js
- Java
- Spring Boot
- MySQL
- Hibernate
- Spring Data JPA
- REST APIs
- Maven

## Features

- User Authentication
- Shopping DNA Score
- AI Personality Insights
- Smart Budget Manager
- Expense Analytics
- Coupon System
- Wishlist
- Shopping Cart
- Recommendation Engine
- Admin Dashboard
- Dynamic Categories
- Achievement System
